# Public practitioner directory

The public directory is separate from authenticated staff accounts and bookable appointment slots. Importing a profile does not create a doctor account, imply endorsement, verify a license or enable appointments. Source URLs and last checked timestamps are retained for each profile. A future operator-controlled linking workflow may connect a verified registered doctor to a public profile through `account_id`; importing never sets this relationship.

Run `npm run directory:import` to import `data/tehran-practitioners.json`, or `npm run directory:import -- path/to/input.json`. Entries require `id`, `displayName`, `specialty`, `categoryId`, `categoryLabel`, `city`, and HTTPS `sourceUrl`; optionally `address`, `phone`, `imageSourceUrl`, and ISO `sourceCheckedAt`. Repeated imports update profiles by ID and preserve successfully fetched photos if a later download fails. Categories are counted from published profiles only.

Photos are downloaded from public HTTPS addresses with checked redirects, request timeouts and a 2 MB bound. JPEG, PNG and WebP signatures are required; SVG and HTML are rejected. Failure is reported as an unavailable photo, and the frontend can display a neutral placeholder. The database stores bytes, media type, source URL and photo-fetch timestamp, avoiding runtime image hotlinking. Publication rights and future refreshes remain operator responsibilities.

`GET /api/practitioners` returns `{practitioners,categories}` using `shared/practitioner-directory.ts`. Each profile exposes source provenance and `photoUrl:null` when absent; photo bytes are served by `GET /api/practitioners/:id/photo`. Hidden profiles and missing photos return 404. The pre-existing `/api/doctors` booking API continues to represent registered staff accounts with actual appointment inventory.

## Tehran source coverage

The reviewed dataset contains 44 unique professional profiles: 25 gynecologic oncology/related clinics, 7 breast surgery, 5 hematology/medical oncology, 4 radiation oncology and 3 breast imaging. This is a source-attributed working directory, not an exhaustive official register of every Tehran physician. Public professional address and contact information is copied from the linked source, without importing patient reviews, rankings, fabricated fees or clinic appointment inventory. Some phone numbers belong to the hospital where the physician practices.

Research is retained in `data/tehran-practitioners-extra.json`, `data/tehran-gynecologic-additions.json`, `data/tehran-photo-patches.json`, `data/tehran-photo-validation.json`, and `data/hadizadeh-photo-patch.json`. Run `node scripts/merge-directory-research.mjs` before importing when updating these files. The final local import has 44 stored raster photographs. Generic source avatars for Behtash, Moradpanah and Ghahghaei were replaced with publicly sourced, visually reviewed professional portraits. A misleading cached Paziresh24 result for Seyed Mohammad Vakili was excluded because its live page identifies Mahsa Sadat Miri. Maryam Moetamedinasab's historical URL was retained only after checking its current physician name and portrait. Azadeh Yousefnejad's specialty follows her current source, which describes obstetrics/gynecology and an oncology clinic, without asserting an unverified fellowship.

Primary sources include [Poorali](https://www.pooralimd.com/), [Cheraghi](https://dr-fcheraghi.com/), [Ebne Sina Hospital](https://ebnesinahospital.ir/), [Nafisi](https://drnafisi.com/), [Tirad imaging](https://tiradsono.com/dr-maryam-pourashraf/) and individual linked clinic pages. Additional public appointment profiles provide professional locations and portraits. The live browser check `npm run test:directory` compares every visible profile with the API, verifies source links and photo decoding, exercises category/search filters, and checks layout at 320, 360, 768 and 1366 pixels without changing development data.
